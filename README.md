# 📊 HR Analytics – AtliQ

## Project Overview

This project is an **HR Analytics Dashboard** created using **Microsoft Power BI**. The dashboard provides insights into employee data and helps understand workforce trends, employee distribution, and key HR metrics.

The main objective of this project is to transform raw HR data into meaningful and interactive visualizations that can support better HR decision-making.

## Objectives

* Analyze employee data and workforce trends.
* Understand employee distribution across different departments.
* Track important HR Key Performance Indicators (KPIs).
* Identify patterns and trends in employee data.
* Create an interactive and easy-to-understand HR dashboard.
* Provide data-driven insights to support HR decision-making.

## Tools & Technologies Used

* **Power BI**
* **Power Query**
* **DAX**
* **Data Visualization**
* **Data Cleaning & Transformation**
* **Microsoft Excel**

## Dashboard Features

The dashboard includes various HR metrics and visualizations such as:

* Total Employee Count
* Employee Distribution
* Department-wise Analysis
* Gender-wise Analysis
* Employee Trends
* HR KPIs
* Interactive Filters and Slicers
* Data-driven HR Insights

## Project Workflow

1. Imported the HR dataset into Power BI.
2. Cleaned and transformed the data using **Power Query**.
3. Created calculated columns and measures using **DAX**.
4. Developed interactive charts and visualizations.
5. Designed an interactive HR Analytics Dashboard.
6. Analyzed the dashboard to identify useful business insights.

##  Key Insights

The dashboard helps HR teams to:

* Monitor overall workforce information.
* Compare employees across departments.
* Understand employee demographics.
* Identify workforce trends.
* Track important HR metrics.
* Make better decisions using data-driven insights.
